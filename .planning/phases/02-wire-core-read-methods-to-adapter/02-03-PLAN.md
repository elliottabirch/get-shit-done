### leak-grep verification idioms (HIGH-1 fix from revision pass 1)

Every `<verify>` block uses Form A / Form C — never `[ "$(...; echo $?)" = "0" ]`:

```bash
# Form A — assert leak-grep PASSES (clean file, exit 0):
node scripts/leak-grep.cjs <file> >/dev/null 2>&1 || exit 1

# Form C — loop:
for f in <files>; do
  node scripts/leak-grep.cjs "$f" >/dev/null 2>&1 || { echo "leak-grep failed for $f"; exit 1; }
```

### Migration Recipe

| Pre-Phase-2 | Post-Phase-2 |
|-------------|--------------|
| `readFileSync(absPath, 'utf-8')` + try/catch | `await adapter.getRecord(planningRelativePath(workstream, relPath))` + null check |
| `existsSync(absPath)` | `await adapter.exists(planningRelativePath(workstream, relPath))` |
| `readdirSync(absPath, { withFileTypes: true })` | `await adapter.listCollection(...)` |
| `readdirSync(absPath)` | `(await adapter.listCollection(...)).map(r => r.name)` |
| `statSync(absPath).isDirectory()` | `(await adapter.stat(...))?.kind === 'dir'` |
| `statSync(absPath).mtime.toISOString()` | `(await adapter.stat(...))?.mtime ?? null` |

### intel.ts mtime pattern (per PATTERNS.md lines 624-655)

Before:
```typescript
if (!existsSync(filePath)) {
  files[filename] = { exists: false, updated_at: null, stale: true };
  return;
}
let updatedAt: string | null = null;
if (filename.endsWith('.md')) {
  try { updatedAt = statSync(filePath).mtime.toISOString(); } catch { /* skip */ }
}
```

After:
```typescript
const intelRel = planningRelativePath(workstream, `intel/${filename}`);
const st = await adapter.stat(intelRel);
if (st === null) {
  files[filename] = { exists: false, updated_at: null, stale: true };
  return;
}
let updatedAt: string | null = null;
if (filename.endsWith('.md')) {
  updatedAt = st.mtime ?? null;  // mtime is optional in stat() return shape per D-11
}
```
