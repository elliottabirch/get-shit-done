Every instance of `Write ".planning/codebase/{NAME}.md"` becomes `gsd-sdk query codebase.put "{NAME}"` with content passed via stdin or args. The workflow currently instructs the agent to write files like STACK.md, ARCHITECTURE.md, CONVENTIONS.md, STRUCTURE.md, etc. to `.planning/codebase/`.

Search for all patterns matching: `Write` followed by `.planning/codebase/` and replace with:
```
gsd-sdk query codebase.put "{docName}" --stdin <<'BODY'
{content}
BODY
```

Or if the workflow uses the Write tool in a "create file at path" instruction format, replace with the equivalent `gsd-sdk query codebase.put` instruction to the agent.

**execute-phase.md (7 leaks: 5 cp-shell, 1 mv-shell, 1 Read-tool):**
- `cp` commands that snapshot `.planning/` state -> `gsd-sdk query state-snapshot` (already exists) or if they snapshot specific phase dirs, describe the intent and use `gsd-sdk query` equivalents

- `Read` that reads a .planning/ file -> replace with appropriate `gsd-sdk query` (likely `init.execute-phase` already bundles the data, or use `state.load`)

- If the workflow is using this for dry-run safety, replace with a note that the SDK's withTransaction handles rollback internally per D-04

**quick.md (5 cp-shell leaks):**
