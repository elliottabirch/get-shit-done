Migration formula for handler migration:
- Old: `const docPath = planningRelativePath(ws ?? null, '${cat}/${name}.md'); await adapter.putRecord(docPath, body);`
- New: `await adapter.putNamedDoc('${cat}', name, body, { workstream: ws });` — adapter computes the same path; `docPath` return value replaced with something the adapter can report (see below).

The handlers currently return `{ data: { written: docPath, name } }`. After migration, `written` is NOT returned by putNamedDoc — the handler recomputes the display path via helpers for backward-compatible result shape:

    function displayPath(workstream: string | null | undefined, category: NamedDocCategory, key: string): string {
      const base = category === 'root' ? key + '.md' : category + '/' + key + '.md';
      return planningRelativePath(workstream ?? null, base);
    }

This helper lives inline in each handler file (or in helpers.ts — planner's discretion; prefer inline to keep helpers.ts unchanged in this plan).
