run:

that matches the fork's own package.json version prefix. Record the

`get-shit-done-cc-<VERSION>.tgz`. The workflow installs this tarball
into the upstream checkout's root via `npm install ../*.tgz`, then runs
upstream's `sdk/src/golden/` vitest suite.

- The parity workflow checks out upstream from a PINNED tag, not a
  floating ref. A compromised upstream tag would fail the parity test

  events; re-pin deliberately on each sync.

  is the same threat surface as the existing `npm ci` in test.yml; no
  new risk introduced by this workflow.

  references). Runs on public forks without authentication.
