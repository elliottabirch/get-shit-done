### leak-grep verification idioms (HIGH-1 fix from revision pass 1)

Every `<verify>` block in this plan uses Form A / Form B / Form C — never the broken `[ "$(...; echo $?)" = "0" ]` idiom:

```bash
# Form A — assert leak-grep PASSES (clean file, exit 0):

  node scripts/leak-grep.cjs "$f" >/dev/null 2>&1 || { echo "leak-grep failed for $f"; exit 1; }

```

### Migration Recipe (verbatim from Plan 1's locked recipe)

| Pre-Phase-2 fs call | Post-Phase-2 adapter call |
|---------------------|---------------------------|
| `readFileSync(absPath, 'utf-8')` + try/catch ENOENT | `await adapter.getRecord(planningRelativePath(workstream, relPath))` + null check |
| `existsSync(absPath)` | `await adapter.exists(planningRelativePath(workstream, relPath))` |
| `readdirSync(absPath, { withFileTypes: true })` | `await adapter.listCollection(planningRelativePath(workstream, relPath))` (returns RecordRef[]) |
| `readdirSync(absPath)` | `(await adapter.listCollection(...)).map(r => r.name)` |
| `statSync(absPath).isDirectory()` | `(await adapter.stat(planningRelativePath(...)))?.kind === 'dir'` |
| `statSync(absPath).mtime.toISOString()` | `(await adapter.stat(planningRelativePath(...)))?.mtime ?? null` |

### Path Normalization (Plan 1 D-04)

| Pre-migration absolute path | Post-migration `.planning/`-relative path |
|----------------------------|-------------------------------------------|
| `paths.state` | `'STATE.md'` |
| `paths.roadmap` | `'ROADMAP.md'` |
| `paths.requirements` | `'REQUIREMENTS.md'` |

| `join(paths.phases, dir)` | `'phases/' + dir` |
| `paths.todos` (or pending todos dir) | `'todos/pending'` |

### Handler Signature Change

Per Plan 1 Shape A: handlers take `adapter: StorageAdapter` as the FIRST parameter. Registration in `createRegistry` uses a closure wrapper:

```typescript
// Handler signature
export const findPhase = async (
  adapter: StorageAdapter,
  args: unknown[],
  projectDir: string,
  workstream?: string,
): Promise<QueryResult> => { /* ... */ };

// Registration in sdk/src/query/index.ts
registry.register('find-phase', (args, projectDir, ws) =>
  findPhase(adapter, args, projectDir, ws),
);
```

### Pitfall 3 (redundant exists before list)

`MarkdownAdapter.listCollection` swallows ENOENT and returns `[]`. After migration, an `if (!await adapter.exists(dir)) return [];` followed by `await adapter.listCollection(dir)` is REDUNDANT — drop the exists check, just call listCollection. Plans 2-3 explicitly remove these.

### Pitfall 2 (Promise.all for tight loops)

`audit-open.ts` walks `phases/*` then per-phase reads ~3 docs (PLAN, UAT, RESEARCH). Pre-migration: nested sync loops. Post-migration: each call is async; use `Promise.all` for parallelizable per-phase reads to avoid serial-await overhead. Recommended pattern:

```typescript
const phaseRefs = await adapter.listCollection('phases');
const results = await Promise.all(
  phaseRefs.map(async (ref) => {
    const [plan, uat, research] = await Promise.all([
      adapter.getRecord(`${ref.path}/PLAN.md`),
      adapter.getRecord(`${ref.path}/UAT.md`),
      adapter.getRecord(`${ref.path}/RESEARCH.md`),
    ]);
    return { phase: ref.name, plan, uat, research };
  }),
);
```
