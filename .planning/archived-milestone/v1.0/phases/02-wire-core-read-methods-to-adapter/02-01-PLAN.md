### leak-grep verification idioms (HIGH-1 fix — apply EVERY <verify> block in Plans 1-5)

Plans previously used the broken idiom `[ "$(node scripts/leak-grep.cjs <file>; echo $?)" = "0" ]`. That idiom captures the script's STDOUT (leak match lines) plus a literal exit-code echo from the OUTER subshell — not the leak-grep exit code. EVERY revision in Plans 1-5 replaces it with one of these explicit forms. Reference these by name (Form A/B/C) in task instructions:

```bash
# Form A — assert leak-grep PASSES (clean file, exit 0):
node scripts/leak-grep.cjs <file> >/dev/null 2>&1 || exit 1

# Form B — assert leak-grep FAILS (leaky fixture, exit 1):
node scripts/leak-grep.cjs <file> >/dev/null 2>&1 && exit 1 || true

# Form C — loop over multiple files, all must pass:
for f in <files>; do
  node scripts/leak-grep.cjs "$f" >/dev/null 2>&1 || { echo "leak-grep failed for $f"; exit 1; }
done
```

### MarkdownAdapter.stat() — copy verbatim into adapters/markdown/index.ts after `exists()`

```typescript
// Update import at line 23 to add stat (renamed to avoid shadowing the method):
import { readFile, writeFile, unlink, readdir, mkdir, stat as fsStat } from 'node:fs/promises';

// Add inside the class, after exists():
async stat(path: string): Promise<{ kind: 'file' | 'dir'; mtime?: string } | null> {
  const abs = this.resolve(path);
  try {
    const st = await fsStat(abs);
    return {
      kind: st.isDirectory() ? 'dir' : 'file',
      mtime: st.mtime.toISOString(),
    };
  } catch (err) {
    if ((err as NodeJS.ErrnoException).code === 'ENOENT') return null;
    throw err;
  }
}
```
